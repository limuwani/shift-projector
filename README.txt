4-on / 4-off Shift Projector

Cycle:
Day 1 → Day 2 → Night 1 → Night 2 → Off 1 → Off 2 → Off 3 → Off 4 → repeat.

Open index.html in Chrome/Edge.
Enter one date whose shift is known for sure, select that shift, choose the year, and generate.
The tool also supports Print/Save PDF and CSV export.
No internet is required.
